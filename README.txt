PREVIEW
1. Open index.html in Chrome, Edge or Firefox.
2. An internet connection is needed to load the optional Google Fonts. The website itself works without them.

PUBLISH FREE WITH GITHUB PAGES
1. Create a public repository on https://github.com/
2. Upload index.html to the repository root.
3. Open Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch, select main and /(root), then Save.
5. Wait for GitHub Pages to publish the site and open the URL shown there.
